Failure Modes
-------------

.. dropdown:: MwLogBackend.LogMessageLossOrCorruption
   :name: fmea-mwlogbackend-logmessagelossorcorruption

   .. grid:: 2
      :gutter: 3

      .. grid-item::
         :class: sd-text-center

         :bdg-warning:`ASIL B`

      .. grid-item-card:: Interface

         DataRouterBackend, SharedMemoryWriter, SharedMemoryReader

      .. grid-item-card:: Failure Effect

         Diagnostic and verification data is missing or misleading. mw::log is not itself a safety-actuating function, but missing or corrupted logs can hide evidence needed for post-incident or verification analysis.

   .. grid:: 1

      .. grid-item-card:: Description

         A log message is lost, dropped, or its content is corrupted between being recorded by the frontend and reaching a configured backend sink.
